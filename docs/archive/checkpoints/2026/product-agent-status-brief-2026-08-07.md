## What the agent is now

The agent is becoming a source-backed investment research and valuation
operator with deterministic finance engines. It is not a generic chatbot and it
is not an autonomous stock picker.

Current operating chain:

```text
official/manual source
-> immutable source custody and hash
-> extraction candidate with exact locator
-> human review and normalized fact
-> Damodaran doctrine and dated benchmark retrieval
-> assumption proposal with provenance
-> deterministic valuation and diagnostics
-> thesis/evidence/alert/portfolio context
-> reviewed decision record
```

The strongest agent behaviors are:

- refusing to promote unreviewed financial facts
- preserving exact source and evidence locations
- separating Fact, Calculation, Estimate, User Assumption, and AI Interpretation
- building FCFF valuations with reinvestment, ROIC, WACC, terminal consistency,
  equity bridge, sensitivity, and reverse-DCF foundations
- using India/Global/US Damodaran benchmarks as dated priors rather than answers
- exposing missing, stale, partial, unsupported, and not-configured states
- keeping private work local unless an explicit provider action is requested

The weakest agent behaviors are:

- no broad automated India filing/fundamentals provider
- only representative, not broad, real-source financial certification
- incomplete contradiction, change-attribution, and evidence-ledger workflows
- incomplete point-in-time replay of every research and portfolio decision
- shallow multi-currency, corporate-action, benchmark, and performance attribution
- fragmented legacy frontend sections and incomplete browser coverage
- AI outputs are governed, but not yet consistently citation-complete by default

## What is still missing before world class

1. One integrated daily workflow from source change to reviewed decision.
2. Broad real-source financial coverage beyond two reference companies.
3. Point-in-time snapshots for every material research, valuation, and portfolio state.
4. Contradiction and thesis-falsification engines tied to exact evidence.
5. Valuation change attribution from old assumptions to new evidence.
6. Portfolio time-weighted returns, benchmark attribution, FX, and corporate actions.
7. A compliant structured India source provider or a polished manual-first equivalent.
8. Background run control, retry/cancellation, and user-visible operational history.
9. Consistent frontend composition across all legacy pages and mobile workflows.
10. Citation-complete AI research with a larger evaluation corpus.
