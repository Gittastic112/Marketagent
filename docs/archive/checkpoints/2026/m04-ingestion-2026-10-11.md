## Implementation

US/India history uses America/New_York and Asia/Kolkata calendar boundaries.
The current market-local date is excluded, including after that day's close;
this is a conservative cutoff, not an exchange holiday calendar or independent
certification of the provider's close. History is bounded to 1-3650 calendar days.
Quotes retain unknown timing. Previously stored rows are not reclassified.

Personal-use SDK calls now run in one-use Linux child processes: 45-second wall
deadline, 10-second CPU limit, 768 MiB address space, 8 MiB result limit, descriptor
and core limits, and at most two concurrent children per API/worker process.
Cancellation/timeouts kill and reap the process group. No application/provider
credentials or environment proxies enter children; their cache is temporary.
This contains resource use, not arbitrary native-code/filesystem access or all
internal SDK network behavior.

FRED and Alpha Vantage share a bounded fixed-host JSON transport with verified
TLS, no redirects/proxies/compression, and sanitized errors. Required query keys
stay out of HTTPX URL logging. Network reads return after one buffered read so
elapsed checks can stop slow trickles. Alpha Vantage history sorts and filters
dates against the same market policy; no fallback or paid feed was enabled.

Price persistence validates security identity as well as market/currency, and
serializes writes for one company after network work. Cancelled attempts finish
as failures without partial prices. Price attempts retain parent-run IDs; a
restarted source worker closes interrupted child attempts, preserves completed
children, and requires an explicit retry.

## Validation

The full source-mounted backend suite passes **1,384 tests**, with five existing
upstream deprecation warnings. Focused tests cover DST/UTC crossover/weekends,
unfinished/future/out-of-window bars, real process cancellation/reaping, CPU,
memory/output limits, busy capacity, malformed results, secret/proxy exclusion,
query-key log sanitization, response caps, identity rejection, idempotent imports,
atomic failure and interrupted-child audit. The SDK imports within its actual
resource budget and all 11 live checks pass through the new process boundary.
