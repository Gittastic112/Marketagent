## PDF and outbound boundaries

Financial PDF extraction, private-source extraction, page geometry and rendering
now run in single-use Linux children. Each has 8 seconds of CPU, a 12-second parent
deadline, 512 MiB address-space ceiling, 16 MiB output ceiling and descriptor/core
limits. Two jobs per API process may run concurrently. Children receive no database,
provider or session environment. Timeouts kill and reap the process group and release
capacity. Busy/unavailable responses are 503; content errors are bounded/sanitized.
Existing upload, page, pixel and text limits remain. This contains resources, not
arbitrary native-code execution or all filesystem access. No malware-disarm claim.
The supported runtime is Linux Docker; unsupported native runtimes fail closed.

SEC metadata and companyfacts now share the DNS-pinned public download transport,
verified TLS, no redirects/proxies/compression, byte ceilings and elapsed checks.
Gemini streams at most 2 MiB through a no-proxy/no-redirect client and never logs
credential headers or rejected source content. FRED retains its required query key
outside HTTPX URL logs, accepts only its exact HTTPS endpoint, disables proxies and
redirects, bounds JSON at 5 MB and sanitizes failures. FRED/Gemini rely on normal
verified-TLS DNS for fixed hosts; they are not arbitrary URL fetchers. The yfinance
library has separate cookie/retry/timeout behavior and remains an explicit limitation.

## Reproducibility and operating-system review

The 66 runtime and 70 test Python versions from the accepted M02 image are retained
in hash-checked locks. Direct manifests remain the edit surface; a drift check rejects
missing hashes, manifest/version mismatch and runtime/test disagreement. Runtime
images omit test packages. Python/Node bases and CI actions use verified immutable
references. Debian security updates use the October 11 snapshot with signed package
verification and fail on incomplete index updates. Node's minimal base bootstraps
CA certificates through Debian's signed HTTP archive before retaining HTTPS sources.
No application dependency upgrade was introduced by locking.

Trivy 0.75.0 scans local image archives without a Docker socket or source-folder mount.
Complete inventories retain every severity. CI blocks HIGH/CRITICAL findings with an
available vendor fix and preserves all reports, including unfixed findings. This gate
is deliberately narrower than a clean security assessment. The normal app still runs
M01 images. No normal PostgreSQL replacement or data migration occurred.
