## Implemented ownership changes

- 136 server actions now have eight domain owners plus a server-only shared
  helper. The old named imports remain. Behavioral tests exercise authenticated
  client calls, payload normalization, exact text/zero offsets, failures, redirects,
  AI disclosure, schedule saves and optimistic draft promotion.
- The HTTP schema facade now only re-exports 193 moved classes and ten literal
  aliases, alongside the existing extracted valuation/portfolio contracts.
  Before/after comparison found identical OpenAPI for 279 paths and identical
  JSON schemas for 260 public contracts.
- Peer inputs and deterministic calculations/receipt hashes are separate from
  owner-scoped persistence. Autofill separates financial lookup, provenance and
  draft orchestration. Workbook parsing/validation is independent of persistence.
  The single market-provider factory remains authoritative.
- Data Health has a request loader and presentation component. Peer and draft
  review have controllers, field definitions and views. Identity-keyed sessions
  and request invalidation prevent obsolete callbacks updating another scope.
- A checked-in manifest ties 15 critical backend contracts to frontend types.
  Backend tests reject an outdated manifest; frontend tests check actual possible
  JSON values, including aliases, enums and nulls. This found and corrected the
  nullable error-target type. It is explicit initial coverage, not a generated
  client or a claim that every frontend type is now covered.
