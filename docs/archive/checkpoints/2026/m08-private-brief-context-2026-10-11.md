# M08 private evidence in deterministic briefs

October 11, 2026. Source implementation is verified with isolated Mock Data.
M08 remains in progress; reviewed AI quality and genuine morning-use proof are open.

Comparison v2 distinguishes same, unknown and incompatible quoted period, currency
and economic-scope labels. Labels must occur literally in the cited passage; source
dates are never inferred to be forecast periods. Matching labels do not establish
economic equivalence, agreement or contradiction. Copied content remains excluded
from independent-evidence claims. Existing v1 receipts remain readable, immutable
and stale against v2 semantics. New scans use prompt `brief-source-v3`.

Manual and due scheduled deterministic briefs now save `private-research-snapshot-v1`
context. Reads are owner-scoped and bounded to ten active-source companies, twenty
distinct source contents and thirty decisions. Six SQL reads suffice for one company;
the ten-company bound is 42, without full source bodies, PDFs or receipt bodies.
Limits, exclusions, source dates, hashes, AI provenance and receipt IDs are retained.
No AI/provider request is made by this snapshot service.

Current analyst receipts with approved source interpretations can enter reviewed
context. Pending AI, missing/stale receipts, incompatible bases and truncated source
sets remain a separate queue. Rejected, foreign, archived, future and Mock Data
sources are excluded. A receipt remains a User Assumption, never a financial-input
approval. Saved brief evidence stays as generated after later archiving or review;
links lead to current sources or the immutable receipt. Legacy briefs explicitly
have no private snapshot. No historical data or valuation assumption is rewritten.

Focused tests cover all three incompatible dimensions, absent/unquoted labels,
owner/review states, copied text, query/materialization bounds, limits, old receipts,
archive changes, immutable snapshots and a due scheduler cycle without AI. Existing
consent, source lifecycle, timeout/late-result and receipt-concurrency tests remain.
The complete source suite passes those consent/provenance/owner/review guards;
M08-05 closes for the implemented boundary. It is not an AI-quality evaluation.
Browser evidence and full integration checks are in the
[M09 checkpoint](m09-browser-validation-2026-10-11.md).

The change crosses pure contracts, comparison/snapshot services, manual/scheduled
callers and UI because the saved evidence must keep the same semantics end to end.
Exact quote validity remains separate from human assessment of interpretation.
The [single ledger](../../../agent_capabilities_and_limitations.md) owns remaining
coverage, human-review and normal-runtime limitations. No migration was added.
