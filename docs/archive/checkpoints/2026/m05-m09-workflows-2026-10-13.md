## Populated price-history repair

Normal rollout verification timed out on Market Prices. Inspection found an
unbounded database query and a full edit form for every stored price. Acceptance
failed safely: previous containers were restored and failed artifacts retained.
The exact failing browser operation was not captured in that first run; subsequent
diagnostics identify navigation, streamed content, accessibility and screenshots
separately. The unbounded query and DOM are fixed regardless of that uncertainty.

The page now requests 51 rows in SQL and displays 50, retaining the extra row only
to determine whether another page exists. Ticker filtering and previous/next links
keep older records reachable. Optional bounded limit/offset preserve the legacy
full-history API and separate complete CSV exports. Live edits can shift offset
pages; refresh the filtered list after changes. No database migration or deletion.

Thirteen backend cases cover filtering, bounds, stable date/ID ordering and actual
51-row materialization. Rendered tests check the 50-form bound and empty/invalid
page recovery. A browser fixture traverses all 103 synthetic prices, checks mobile
bounds and unchanged records, and verifies an unmatched filter. The import/export
workflow now uses the ticker filter to locate its dated imported row.
The retained mobile screenshot was inspected at native width: fields and filter
actions fit their panels, and the data table scrolls within its bounded wrapper.
