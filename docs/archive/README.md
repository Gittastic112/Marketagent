# Documentation Archive

These files are preserved for historical evidence. They are not current
instructions and may contain obsolete paths, counts, priorities, or design ideas.

| Folder | Contents |
|---|---|
| [`checkpoints/2026/`](checkpoints/2026/) | Dated shipped-work evidence and validation records |
| [`handoffs/`](handoffs/) | Superseded cumulative handoffs |
| [`assessments/`](assessments/) | Previous current-state, architecture, schema, runbook, and capability audits |
| [`plans/`](plans/) | Superseded product, provider, valuation, and platform plans |
| [`research/`](research/) | Dated external-provider and API research |
| [`agent-instructions/`](agent-instructions/) | Superseded agent instruction drafts |
| [`instructions/`](instructions/) | Prior repository/nested operating instructions |
| [`needs-review/`](needs-review/) | Historical documents never promoted to current truth |

Use `rg --files docs/archive | sort` to inventory everything. Internal links in
archived bodies are not maintained after moves; archive README navigation is checked. Search by basename if a historical
link no longer resolves.

Do not move a document back into the active set without reconciling it against
current code, tests, and the current documentation architecture.
