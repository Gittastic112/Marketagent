# Current state

November 21, 2026. The personal research/demo installation runs the November 20 release, including the dated first-valuation preview and decisions on pinned stock prices. A new installation starts with its own database. The [user guide](user-guide.md) describes the workflows and the [feature register](roadmaps/feature-register.md) records their implementation status.

## Product position

| Workflow | What is available |
|---|---|
| Today and Daily Brief | A dated portfolio summary, brief and active alerts come before the six-item research queue. Stored input counts, source links and review status are visible. Private brief intake supports text and PDF with optional, consented AI review. |
| Company research | Filing and event evidence, annual financial review, private theses and dated decisions. The chart supports a private decision on a specific thesis assumption, anchored to the original closing price. |
| Valuation | Reviewed drafts can bind dated source revisions, preview a first calculation and save its inputs and reason. Saved-model edits, scenarios, sensitivities, reverse DCF and reviewed peer comparisons remain available. The selected date on financial evidence alone does not rebase a model. |
| Portfolio | Recorded activity, dated snapshots, returns, attribution, benchmark comparison and price risk. The example holdings are hypothetical. |
| Adapters and Research Lab | Explicit market and source actions, candidate peers, hypothetical allocations, simulations and report exports with saved inputs and hashes. The analysis and Camelot profiles were installed. [Adapter guide](adapters/README.md) |
| Operations | Local sign-in, owner-scoped records, optional workers, Processing Runs, schema readiness and recovery tools. The source-refresh worker is opt-in. |

Selecting Apple's November 4 move opened its details, the preceding close's evidence and the private note controls. The two superseded application images were removed. Four containers and one verified recovery set were retained. [Operating procedure](operations.md#select-the-installed-local-stack)

**November 21 issuer workflow check.** On an isolated restore of the existing recovery set, the candidate applied consolidated annual revenue and net income from four original SEC filings. Each fresh draft still needed reviewed inputs before it could calculate a value. The stock charts showed 33 moves of at least 5% across 1,000 stored closes. Six had a non-sample original attached to that close or the preceding close. Retrying each test pin and thesis decision preserved the selected price and returned the original record. The test counted zero days of personal research. [Issuer figures, remaining draft fields and source coverage](../data/reviews/issuer-workflow-verification-20261121.json)

**November 20 release candidate.** An explicitly selected consolidated annual revenue revision produced USD 13.50 per share in the controlled example. Preview made no model. First confirmation created one model, one assumption version, one output, ten projection rows, six sensitivity rows and one decision receipt. A retry after a subsequent source revision returned the same version. The independent PostgreSQL suite covered concurrent confirmation and revision publication. The operating tests passed 2,287 cases with 47 skips, the separate PostgreSQL suite passed 30 and the frontend passed 426. The production UI built successfully and 81 repository and recovery checks passed. In Firefox, retrying a first valuation after a lost response returned the saved model. A separate chart check followed the filing to a thesis, retained the USD 90 pinned close after a correction to USD 93, and reopened the saved decision. Both workflows used Mock Data. An isolated restore and upgrade of the retained recovery set preserved 109 original business-table fingerprints and the stored PDF. A personal research day requires actual user use.
