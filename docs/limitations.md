equities, with USD portfolio reporting. The November 9 scope covers four selected

create local disposable datasets, or grant external-AI permissions as a setup or
cleanup side effect. Delegated review authorizes supported, recorded judgments;

## Valuation boundary

A valid formula can still produce an economically unsupported estimate. Review
financial basis, currency/scale, growth, margins, reinvestment, discount rate,
terminal assumptions, equity claims, and diluted shares. Outputs structure
judgment; they must not issue buy/sell instructions.

| Method or consumer | Boundary |
|---|---|
| Core FCFF | Explicit zeros survive; missing-value presets still exist, including an internal missing-share fallback that diagnostics/display must block. Historical saved outputs are not recalculated on read |
| Calendar basis | Projections use relative periods. Calendar years remain null without a fiscal anchor; legacy unanchored years are withheld. Old integer-only images cannot safely consume new nullable rows |
| Sensitivities and scenarios | Canonical FCFF sensitivities retain saved funding/terminal assumptions and per-cell validity. Legacy grids remain unverified. Shocks are deterministic scenarios, not probabilities; unsupported specialized tables stay unavailable |
| Reverse DCF | Requires valid owned saved inputs and actual convergence. Financial-services reverse analysis is unsupported. Bisection does not prove a unique root or find every possible root |
| FCFE/DDM | Explicit finite cost of equity, growth, shares, and complete cash-flow components are required. Single-stage stable-growth estimates do not prove sustainable payouts. Zero dividends do not imply zero economic value |
| Payout comparisons | Dividends, buybacks, and issuance must all be explicit and finite. Comparisons do not establish funding, stock-compensation causation, or value destruction |
| Financial services | Simplified excess-return model with linear ROE fade and constant book-equity growth, not a regulatory-capital/payout forecast. Equity-specific inputs and scenarios remain mandatory |
| Distress | Probability and common-equity recovery after senior claims require explicit review. Base projections remain conditional on survival. No independent recovery-review receipt; unadjusted supplementary values are withheld |
| Real Options | Experimental, non-persisted supplemental analysis for a reviewed owned FCFF basis. Seven eligibility confirmations and equity/currency/scale assertions are user judgments. Simplified Black-Scholes/exclusivity assumptions; no bank/distress integration |
| Legacy option endpoints | Deprecated custom-base endpoints remain compatible but do not enforce the saved-basis panel contract. Their historical outputs are not certified |
| Saved values and versions | Price/input values are User Assumptions; diagnostic scores are historical. Version/hash gates prevent stale saves but do not validate source facts. A new saved version is needed to apply corrected calculations |
| Legacy UI callers | Mounted advanced-workspace behavior has focused evidence. Older unmounted form callers retain separate formatting/default and browser-verification limits |
| Macro sensitivity | Single-factor OLS is not causality, significance, or stable exposure. Constant/missing factors remain unavailable; partial segments are not renormalized into a company total. Units and shock directions require review |

## Relative valuation and peer review

Peer review is an owner assertion, not independent market-data verification.
Each method needs at least three positive eligible observations. A current
diagnostic receipt proves that specific displayed warnings were acknowledged,
not that the facts, accounting, periods, or comparability are correct.

- Edits, restores, evidence changes, and time-sensitive warnings can invalidate
  receipts. Data Health checks on request, not in the background.
- Audits are bounded to 100 sets per API response (50 in the UI); counts are
  page-local. Cursor pages are live reads, not an immutable global snapshot.
- CSV preview is non-writing. Apply requires the exact hash, is owner/company
  idempotent, and creates Draft evidence. Limits are 1 MB and 50 peers.
  Legacy pre-receipt imports can create one additional draft on their first retry.
- Market-cap comparison requires matching stated currencies. There is no FX
  normalization, accounting normalization, peer weighting, or calibrated score.
- Saved DCF inputs preserve explicit zeros and disclose their basis. EBITDA
  remains unavailable without complete D&A evidence. Currency/share scales and
  the simplified bridge still require confirmation.
- Stale browser requests cannot restore obsolete results, but cancellation is
  logical rather than transport abortion. Remote edits still require refresh.
  Backend calculation checks remain independent.

## AI boundary

External AI requires both current feature disclosure and persisted
owner/provider/action permission. New outputs retain the exact permitting
decision, provider/model, prompt version, input hash, sources, generation time,
confidence, limitations, and review state. Migration or read activity grants
nothing. Revocation cannot recall already transmitted data.

Exact citations and bounded schemas do not certify economic meaning. Evaluation
v4 inspects at most 100 markers/100,000 characters; flagged or truncated reviews
require rationale. Literal number/period/instruction cues are aids, not a truth
score. Citation edits reset approval and preserve the prior receipt.

The selected delegated review of six actual responses and four adversarial
fixtures is limited evidence, not a statistical accuracy or injection-resistance
claim. Original human verdicts remain unchanged. AI cannot silently approve
financial facts, overwrite assumptions, or send undisclosed private app data.
The operator-only connectivity probe uses fixed non-private text.

## Research and briefing boundary

| Workflow | Boundary |

| Private PDF intake | 12 MB, twenty selected pages, and 60,000 extracted characters per source. No OCR, chart interpretation, malware disarm, or visual table certification |
| Retrieval | Owner-scoped literal phrase search over stored text and titles, not semantic search or a large-corpus performance claim. Only extracted PDF pages are searchable |
| Comparison | At most 50 active sources. Quoted same/unknown/incompatible period/currency/scope labels do not establish semantic contradiction or independent corroboration |

| Business descriptions | Bounded annual-filing excerpts with source dates, not live curated profiles |
| Extraction evaluation | Executes the supported local text parser against reviewer-asserted reference rows. Missing units fail. This does not certify PDF/XBRL/AI coverage, reference truth, or forecast calibration |

## Portfolio boundary

Recorded dated activity is not broker-verified execution. Replay rejects missing
openings, oversells, negative cash, ambiguous identity, unsupported adjustments,
and more than 20,000 rows. Same-day record order is not verified settlement order.

New snapshots retain activity/hash/FX provenance; legacy/manual history and later
corrections remain provisional without rewriting old snapshots. TWR uses the
selected period; annualized MWR uses the first cash flow. Fixed-weight price risk
is not realized total return. Alignment must match interval endpoints and cannot
bridge missing interior FX. Annualization assumes 252 periods without exchange
calendar certification. Prices older than five days withhold current DCF gaps.

Existing examples and arithmetic checks do not establish genuine activity,
complete DCF/benchmark coverage, or independent financial-model review.

## Security boundary

| Area | Remaining limit |
|---|---|
| Internet exposure | Production identity/MFA, broader authorization tests, TLS, CORS/CSRF review, persistent throttling, security logging, least-privilege database roles, and an OpenAPI exposure decision remain prerequisites |
| Host protection | Firewall/FileVault/account/sharing status is not certified. The earlier host work is deferred; do not infer protection from hardware or localhost bindings |
| Recovery/privacy | Same-disk backups do not protect against loss of the device. Dumps contain private research and are not application-encrypted. Off-device encryption and recoverable keys remain open |
| Parser isolation | Bounded Linux child processes limit CPU/memory/time/output/concurrency; they are not an arbitrary-code/filesystem sandbox or malware scanner |
| Outbound clients | Bounded transport and DNS controls are adapter-specific. In-flight reads do not guarantee strict elapsed cancellation; SDK endpoints and native-code/filesystem behavior are not fully sandboxed |
| Browser and throttles | Basic headers/CSP are not a strict nonce policy. Login limits are per-process; proxy requests share backend IP-based limits |
| Dependency/container scans | Results are dated and retain unfixed/applicability findings. Optional stopped services and the host require separate assessment; scans do not certify exploitability or completeness |
| Secret scan | Heuristic working-tree checks are not full-history analysis or credential revocation. Protected settings are not read by a documentation cleanup |
| Backup formats | Format 3 verifies completion marker, dump content, fingerprints, and both PDF stores; format 2 stays readable. Opt-in format 1 is weaker. Flushes are not a full power-loss guarantee; incomplete backups remain unavailable |

The [threat model](security.md) owns security design.
[Operations](operations.md) owns recovery, worker coordination, and credential
procedures. Historical successful drills do not replace an explicitly scoped
populated restore or prove off-device recovery.

## Architecture follow-ups

- Domain contracts and server actions are extracted, with compatibility facades.
  Large remaining workflow modules need behavioral boundaries before further moves.
- Market adapters still span providers and services/market_data. Keep the existing
  factory authoritative until a tested migration removes that split.
- Frontend types remain manually synchronized. Generated contracts need an
  explicit plan for aliases, envelopes, and response-only reconciliation.
- Source-integrity tests complement rendered and browser tests. They do not
  certify every form state, legacy caller, screen reader, or concurrent-user load.
- Four-concurrent-request portfolio loading and query budgets are local guards,
  not global throttling or a capacity certification.
- Unique test projects prevent accidental target reuse; default ports and shared
  image tags still require coordinated test lanes.
- Host tools and dependency trees can differ from the supported locked images.
  Use the [runbook](execution-runbook.md); report unavailable checks accurately.
