# Information, Earnings and Expectations

Market reaction is driven by information relative to expectations, not by whether a reported number looks good in isolation.

For earnings/events capture:
- actual result
- consensus immediately before release
- consensus 30/60/90 days earlier
- revisions into the event
- management guidance
- historical surprise pattern
- inferred/whisper expectation when defensible
- market price reaction
- whether the new information changes intrinsic value drivers

A company that routinely beats consensus can create an implicit expected beat. A nominal positive surprise can therefore produce a negative price reaction.

Separate:
- `fundamental surprise`: changes revenue/margin/reinvestment/risk/value
- `expectations surprise`: changes price because expectations were different
- `both`

Document ingestion priority:
1. financial statements
2. footnotes/segment/unit-economics disclosures
3. operating KPIs and capital spending
4. useful MD&A
5. guidance
6. generic risk/boilerplate at low default weight

More disclosure does not automatically mean more information.
