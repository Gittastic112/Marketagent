# Raw Sources

Immutable source evidence. Never edit, rename, re-save, normalize, or convert a
file in this directory after routing. Derived text, formula maps, and summaries
belong in `reference/`, `core/`, `knowledge/`, or `data/`.

Routing:

- `articles/`: general articles, notes, and empirical-regression PDFs
- `cases/`: company-specific worked evidence
- `datasets/`: dated benchmark, industry, and country tables
- `models/`: reusable spreadsheets and tools
- `inbox/`: unprocessed originals only

Use `data/raw_file_hashes.csv` to verify canonical bytes and
`data/processing_ledger.csv` to trace intake decisions.
