# Local helper packages

These folders contain local guidance and supporting files. Their presence does
not install a plugin, enable a connected service or prove a skill is available in
the current agent session. Use the session's skill catalog for installed tools.

| Folder | Purpose |
|---|---|
| [security-review](security-review/) | Project-specific security review package |

Local copies of Playwright, PDF, spreadsheet and connected Excel helper packages
may also exist on this Mac. They are retained locally, outside the publication
snapshot. They are not application dependencies; use the installed skill catalog
for their availability and licensing rather than redistributing those copies.

The [relocation inventory](../scripts/retired/inventory-2026-10-25.json) preserves
original paths and hashes. Current application workflows live in
[docs/skills](../docs/skills/README.md); those workflows and these helper packages
serve different purposes. Neither folder contains application runtime code.
